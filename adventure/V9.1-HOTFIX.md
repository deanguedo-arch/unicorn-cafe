# Sneaky Unicorn v9.1 hotfix

The v9 mechanics rewrite removed the JUMP and SNEAK controls, but `clearInput()` still attempted to access those deleted DOM elements. That caused a runtime exception whenever input was cleared during startup/menu transitions.

## Fix
- `clearInput()` now clears only the existing RAINBOW BLAST button state.
- No JUMP/SNEAK DOM lookup remains.
- PWA cache bumped from `9.0.0` to `9.0.1`.
- In-game build label bumped to `V9.1 / RAINBOW ADVENTURES`.
