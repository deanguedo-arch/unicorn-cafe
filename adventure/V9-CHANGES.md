# Sneaky Unicorn v9 — Rainbow Patrol

## Core rule rewrite
- Removed JUMP and SNEAK from gameplay.
- Added one large translucent RAINBOW BLAST button.
- Removed visible vision cones and all sight/hearing chase logic from active gameplay.
- Opponents follow patrol routes only.
- Patrol speed changes gently every few seconds for variety.
- Touching an active opponent resets only the unicorn to the level start; carried and delivered loot are retained.

## Treasure adventures
- Big Cozy House, Big Friendly Market, Moonlight Restaurant, and Twinkle Toy Store remain playable.
- There is no three-item finish prompt.
- Every treasure on the level must be delivered before the level ends.
- Raised/tabletop treasure can now be collected from beside the furniture because JUMP no longer exists.
- Rainbow-blasting an opponent sends them to the visible jail lane for about 2.65 seconds; then they resume their route.

## Police Unicorn Patrol
- New fifth playable level built on the open toy-store environment.
- No treasure objective.
- Five bad guys use different patrol routes and base speeds.
- Rainbow-blasted bad guys go to jail and stay there permanently.
- The unicorn wears a simple police cap overlay in this level.
- The level ends immediately when all five bad guys are jailed.

## Controls
- Drag anywhere on the map to steer.
- RAINBOW BLAST fires in the unicorn's most recent movement direction.
- Blast has a generous hit radius and short cooldown for a five-year-old.

## iPhone/offline
- Cache bumped to 9.0.0.
- Existing v1-v8 scoped caches are removed on service-worker activation.
