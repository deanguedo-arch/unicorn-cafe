# Illustrated adventure controls

New UI artwork created locally on 2026-10-05 with the built-in image generation tool. Original imported art is unchanged. These two files are included in the adventure's own offline cache.

- `ui-sound-v1.png`: transparent loudspeaker sprite.
- `ui-settings-v1.png`: transparent settings gear sprite.

Style references: original `sofa` and `jump_icon` assets from adventure/index.html. Both new images retain the generated transparent alpha without cropping or resizing.

Sound prompt: A single transparent pixel-art game UI icon matching Sneaky Unicorn's chunky dark-purple outlines, luminous purple/pink surfaces, gold accents, crisp pixel steps and painted highlights. One friendly lavender-purple loudspeaker with a golden cone and two short gold sound waves. Slight three-quarter sprite perspective matching the reference sofa and jumping unicorn. Center the entire object in a square with generous transparent padding. No circle, badge, button container, text, letters, watermark, surrounding decoration or blur.

Settings prompt: A single transparent pixel-art game UI icon with the same reference style. One front-facing golden settings cog with eight chunky teeth, lavender-purple inset center and round gold center pin. Subtle dimensional sprite shading and white pixel highlights. Center the entire gear in a square with generous transparent padding. No circle or badge behind it, button container, text, letters, watermark, surrounding decoration or blur.

Place cues reuse original sofa, apple, cupcake and toybox assets plus the existing pumpkin dumpling sprite rectangle. Each tile contains one picture fitted proportionally, without a circle or overlapping image composition.
