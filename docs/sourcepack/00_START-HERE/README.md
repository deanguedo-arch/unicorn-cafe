# Sneaky Unicorn — Reusable Source Library

This folder is the long-term source pack for **Sneaky Unicorn** and related future games.

## Start here
1. Read `../01_CANONICAL/UNIVERSE-BIBLE.md`.
2. Read `../01_CANONICAL/GAMEPLAY-v14.md` for the current rules.
3. Read `../01_CANONICAL/DEPRECATED-RULES.md` before using any historical document.
4. Use `../03_ASSETS/ASSET-CATALOG.md` to find the right artwork.
5. If building a new game, start from `../06_FUTURE-GAMES/REUSABLE-BUILDER-PROMPT.md`.

## What is canonical?
The **v14 top-down game direction** is current. Historical files are included for provenance and lessons learned, but they contain older rules that have been intentionally replaced.

Current identity:
- Designed around a young child / roughly age 5–9.
- Top-down, colorful, toy-like action-adventure.
- Drag-anywhere directional movement on phone.
- One large **Rainbow Blast** action button.
- Treasure maps: collect **all** available treasure and return it home.
- Two variable-speed patrol people per normal map.
- Contact causes a gentle sparkly send-back, not a harsh failure.
- Rainbow Blast temporarily sends normal-map opponents to jail, then they return to patrol.
- Police Unicorn map: whimsical Halloween dumpling bad guys; regular bad guys need 3 hits and stay jailed; boss needs 5 hits.
- Two magical secret doors per treasure level.
- Two baby unicorn rescues per treasure level.
- Rescued babies follow behind Mom Unicorn in a duckling-style line.
- Treasure Room, costumes, secret treasures, portal/trap effects, and menu access are part of the current universe.

## Folder map
- `01_CANONICAL/` — current source of truth.
- `02_LATEST-v14/` — latest playable/build source.
- `03_ASSETS/` — reusable artwork organized by role.
- `04_DESIGN-HISTORY/` — old audits, plans, and evolution notes.
- `05_QA-and-BUILD-NOTES/` — later change logs and QA notes.
- `06_FUTURE-GAMES/` — starter material for making new games in the same universe.
- `07_ARCHIVE/` — original project snapshot; useful for provenance, not for current rules.

## Important historical warning
Older docs discuss **JUMP, SNEAK, vision cones, noise rings, giggles/lives, and collect-any-3**. Those are not current v14 rules unless a future game intentionally revives them.
