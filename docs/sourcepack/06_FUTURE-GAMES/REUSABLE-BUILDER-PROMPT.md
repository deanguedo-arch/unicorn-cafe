# Reusable Builder Prompt

Copy this into a new builder session together with the Source Library.

---

You are building a new original game in the **Sneaky Unicorn** universe.

Before doing any implementation, read in this order:
1. `00_START-HERE/README.md`
2. `01_CANONICAL/UNIVERSE-BIBLE.md`
3. `01_CANONICAL/GAMEPLAY-v14.md`
4. `01_CANONICAL/ART-DIRECTION.md`
5. `01_CANONICAL/TECHNICAL-CONSTRAINTS.md`
6. `01_CANONICAL/DEPRECATED-RULES.md`
7. `03_ASSETS/ASSET-CATALOG.md`

Treat `01_CANONICAL` as the source of truth. Historical files are reference only unless I explicitly ask to revive an old mechanic.

Use the source assets rather than approximating their identity. New art should match the established illustrated toy/storybook style and remain readable on a phone.

The intended child audience is roughly 5–9. Favor immediate fun, huge forgiving touch controls, little required reading, obvious rewards, open routes, funny reactions, and short recovery from mistakes.

Do not copy proprietary characters, levels, art, music, logos, or layouts from games used only as high-level design references.

For this new game, first define:
- one-sentence fantasy,
- primary objective,
- control scheme,
- fail/recovery rule,
- 60–180 second vertical-slice level,
- reusable assets from the library,
- any genuinely new assets required.

Then build the smallest complete playable version before expanding content.
