# Future Game Starter

Use this file when making a new game in the Sneaky Unicorn universe.

## Step 1 — Pick the fantasy
Choose one sentence a five-year-old can understand.

Examples:
- Police Unicorn catches squishy Halloween bad guys.
- Sneaky Unicorn rescues baby unicorns from magical rooms.
- Bakery Unicorn collects every cake before the bakers bump into her.
- Pet Shop Unicorn rescues pets and leads them home in a parade.

## Step 2 — Keep controls tiny
Default recommendation:
- drag-anywhere movement,
- one giant context-relevant magic button.

Add a second permanent action only if playtesting proves the first cannot support the fantasy.

## Step 3 — Make the objective visual
Good goals:
- collect all visible treasures,
- rescue all babies,
- catch all bad guys,
- bring all pets home,
- activate all magic doors.

Avoid objectives that require reading a paragraph.

## Step 4 — Create one strong 60–180 second level first
Before building a campaign, prove:
- movement feels good,
- objective is understood without explanation,
- mistakes recover quickly,
- rewards are obvious,
- the child wants to replay.

## Step 5 — Reuse the universe without cloning the same game
Reusable identity:
- main unicorn,
- baby unicorns,
- rainbow magic,
- magical doors/portals,
- treasure-room meta collection,
- bright toy/storybook world.

Mechanics can change between games.

## Step 6 — Phone acceptance test
A new game should pass:
- primary controls can be hit by a child without precision,
- no important art is hidden behind opaque UI,
- camera never reveals accidental black voids,
- no object is visually sliced by a foreground rectangle,
- every mandatory objective is reachable,
- touch can recover from accidental release / re-touch naturally.
