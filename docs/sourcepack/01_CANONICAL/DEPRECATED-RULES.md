# Deprecated / Historical Rules

Historical docs are intentionally preserved, but the following are **not current v14 rules**:

- Permanent JUMP button.
- Permanent SNEAK button.
- Vision cones.
- Noise-ring stealth as the primary gameplay loop.
- CALM → CURIOUS → CHASE vision-state system as the central mechanic.
- Three giggles/lives as the primary failure currency.
- Collect-any-3 as the Easy Adventure completion rule.
- Side-scrolling platformer as the main current format.
- One secret door / one baby per level.
- Human bandit characters in Police Unicorn.

## Why preserve them?
They document useful experiments and may inspire a different future game. If a new title intentionally brings one back, treat that as a new design decision rather than assuming it is still canon.
