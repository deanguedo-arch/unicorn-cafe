## Notes

- The `visual-reference/` folder intentionally contains alternates and presentation art. Future builders should not silently replace the production set with these without a design decision.
- `core-original/` preserves the early character and object identity of the project.
- The latest integrated source embeds optimized copies of some artwork inside its HTML. Keep the full-resolution source art here for future editing/regeneration.
